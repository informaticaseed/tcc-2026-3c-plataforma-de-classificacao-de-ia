1. O que é uma Issue e para que serve no desenvolvimento de software?

Issue é um problema, registro de tarefa ou ideia de um projeto de software.
Serve pra organizar o trabalho da equipe, mostrando o que precisa ser feito e o progresso da atividade.

2. O que é um Pull Request e por que ele é importante?

É um pedido pra modificar alterações no código a um projeto principal.
É importante porque permite que os outros vejam o código antes de ser aceito.
Desse jeito o PR ajuda a evitar erros e facilita o trabalho na equipe.

3. O que é separação de camadas no código?

É uma forma de organizar o código, dividindo o sistema em partes com funções diferentes.
Deixa o código mais fácil de entender.

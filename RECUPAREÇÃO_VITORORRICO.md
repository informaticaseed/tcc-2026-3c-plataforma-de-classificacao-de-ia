1. O que é uma Issue e para que serve no desenvolvimento de software? 
   É uma ferramenta usada para registrar tarefas, problemas, melhorias ou ideias de um projeto software. Ajuda a organizar o trbalho da equipe, mostrnado o que precisa ser feito e quem é o responsável por cada tarefa.

2. O que é um Pull Request e por que ele é importante? Explique com suas próprias palavras:
   É uma solicitação para que as alterações feitas em uma brench sejam analisadas e adicionadas ao projeto principal. Antes de haver mudanças, os outros integrantes podem revisar o código e fazer melhorias. e isso ajuda a evitar errros.

3. O que é separação de camadas no código?
   Divide o programa em partes com funções diferentes o deixando mais organizado. O app.py normalmente é responsável por controlar a aplicação. Já o repositorio.py é responsável pelo acesso aos dados, como salvar, buscar, editar ou excluir informações.
